# Mandate

> Never give an AI agent an unbounded wallet; give it a mandate.

A policy engine that sits between AI shopping agents and PayPal, enforcing hard spending limits in plain code. The agent proposes purchases; the engine decides. No LLM in the money path.

**Status:** Phase 0 — scaffolding and PayPal sandbox gate test.
